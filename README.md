# Controle-de-Chamados-Ticket-System-B-sico-

## 🎫 Sistema de Chamados Básico

Sistema simples de controle de chamados desenvolvido em JavaScript puro. Permite criar, visualizar e alterar o status de tickets de atendimento.

O projeto simula uma funcionalidade comum em sistemas de suporte, destacando lógica, organização de dados e interação com o usuário.

### 🚀 Tecnologias
- HTML
- CSS
- JavaScript
